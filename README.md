## overview

# 🛍️ ShopNest – Shop Smarter, Live Better

ShopNest is a responsive e-commerce web application
built using React.js. It provides users with a simple
and smooth online shopping experience.

## 🌐 Live Demo

https://shop-nest-nine-zeta.vercel.app

## 🚀 Features

- Responsive homepage
- Product browsing
- Product search
- Product details page
- Add to cart functionality
- Update product quantities
- Remove products from cart
- Checkout page
- Easy navigation

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Vite

## 💻 Installation

1. Clone the repository:

   git clone https://github.com/raushan63321-crypto/ShopNest.git

2. Open the project folder:

   cd ShopNest

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open http://localhost:5173 in your browser.
